### 核心版

- 专注歌单、歌单导入、音源、听歌、搜索和下载，首页固定为「我的歌单 / 在线歌单 / 搜索 / 下载」
- 设置收敛为音源、基本、播放、搜索、列表和下载；保留页内歌词、队列、收藏、稍后播放及通知栏控制
- 移除排行榜、评论、多端同步、桌面/蓝牙歌词、定时退出和应用内更新，以及相关专属模块和权限

### 视觉与交互

- 统一 Lucide 图标、明暗色板、大标题、唱片主视觉和浮动玻璃操作层
- 歌单、搜索、播放与下载共用清晰的操作层级，按钮使用独立触控区域
- 横屏侧栏固定设置入口，歌单头部采用紧凑排布；1.3 倍应用字号下仍能看到导航、播放操作和首屏歌曲

### 修复与可靠性

- 修复分享链接与纯 ID 可能重复导入同一歌单的问题，兼容历史歌单身份并保留平台特殊标识
- 保留 JSON、LXMC、BIN 歌单导入与导出；格式校验通过、数据实际保存后才提示成功，取消与失败不会显示假成功
- 所有音源入口共用最多保存 20 个、同时启用 5 个的限制，拒绝空、非字符串及过大的脚本
- 修复下载页浮动播放器空白、旋转回竖屏后仍使用双列、大字号操作裁切等问题
- 改进分片存储写入、下载取消及同名并发任务处理，保留真实失败原因与重试入口
- 修复在线歌单分页与旧请求覆盖新结果的问题，保留用户暂停和启动后恢复暂停的行为

### 升级提示

- 正式包使用原包名与原正式证书；升级前建议导出重要歌单，然后使用与旧版相同的 ABI 安装包覆盖安装，不要先卸载或清除数据
- 既有本地歌单、音源和下载文件继续保留；旧排行榜收藏可播放本地内容，但不再支持更新排行榜
- 应用内更新已移除，后续版本从本仓库 Releases 手动下载
- Preview 与正式版独立存储；Preview 用户需要先导出歌单，再在正式版导入

### 验证与已知限制

- 核心候选通过 115 项 Node 回归、TypeScript、全量 ESLint 和 Android Preview 构建；Android API 25 模拟器已实测导入、音源、播放、搜索、下载 HTTP 503 重试、横竖屏与大字号
- 本次正式发布在打标签前校验五份 APK 的签名证书，沿用 v2.1.9 正式证书
- 真实软键盘布局、其他 ABI 的设备运行与 iOS 尚未验收
- 音源静默初始化/删除生命周期、跨操作歌单事务、中断下载恢复、降级/换源后的实际音质标签仍有既有问题；重要歌单先备份，强制退出后核对下载文件完整性
